# FIIT-labs-2026
## Репозиторий предназначен для сдачи лабораторных работ 1 курса ФИИТ
____
Целью выполнения данных работ **НЕ** является:  
+ Загрузить и показать код, написанный другом
+ Загрузить и показать код, написанный LLM
+ Загрузить и показать код, который вы уже забыли как работает
+ Загрузить и показать код, который вы не можете объяснить
____
### Для того, чтобы сдать работу, Вам нужно:
1. Зарегистририроваться на GitHub. 
2. Установить и настроить себе Git, используя инструкции например [отсюда](https://git-scm.com) или [отсюда](https://docs.github.com/ru/get-started/getting-started-with-git/set-up-git).
3. Сделать fork данного репозитория
4. Склонировать его себе на машину при помощи команды:  
``` 
$ git clone <ссылка>
```
____
### Дальнейшие действия:  
+ После того, как Вы склонируете репозиторий, нужно перейти в директорию (в папку на компьютере со склонированным репозитерием)
```
$ cd FIIT-labs-2025
```
+ Создать и переключиться на ветку, в которой Вы будете работать над лабораторной:
```
$ git checkout -b ivanov_labWork_1
```
В названии ветки доложна быть указана Ваша фамилия.  
#### **Важно!** Следите за тем, чтобы Вы работали в **СВОЕЙ** ветке!
Все файлы работы должны находиться в директории с названием ```<наименование работы>/ФамилияИО``` (например, ```laboratory_work_0/IvanovII```. Директории ```<наименование работы>``` предварительно уже созданы в репозитории).  

Для этого необходимо перейти в директорию с названием работы, которую вы собираетесь выполнять:  
```
$ cd <имя папки>
$ cd laboratory_work_0
```
Создать здесь свою папку с **правильным** названием и перейти в нее:  
```
$ mkdir <имя папки>
$ cd <имя папки>

$ mkdir IvanovII
$ cd IvanovII
```

> ! Не запрещено выполнить эти действия через обычный проводник

Выполнив действия выше, можно приступать к работе)  

### Когда лабораторная будет готова:
+ Подготовьте необходимые файлы
```
$ git add <нужные файлы или ключ -A, если все>
```
+ Зафиксируйте их
```
$ git commit -m "<название/описание коммита>"
```
+ Отправьте изменения:
```
$ git push origin ivanov_labWork_1
```

### После этого сделайте ```Pull request (PR)``` в основной репозиторий (из вашей ветки)
Название pull request должно быть:
```
<Фамилия Имя>. Лабораторная работа <Номер лабораторной>.
Иванов Иван. Лабораторная работа 1.
```

PR не должны содержать изменений любой общей информации вне вашей папки (IvanovII), которая была создана для работы студентом.
